# Changelog

## 1.0.0 (2026-10-15)

First public release for the Qiskit Fall Fest 2026 hackathon (Advanced track).

- `sentinels` Python package: qiskit-paulice checks, Z-safe T doping, exact post-selected fidelity with Qiskit Aer, SamplerV2 validation.
- Exhaustive evaluation of every legal game move for two noise models.
- Web game on GitHub Pages, terminal game (`sentinels play`).
- Experiments E0 to E7, figures, report and slides.
