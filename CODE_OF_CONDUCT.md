# Code of Conduct

This project follows the [Qiskit Code of Conduct](https://github.com/Qiskit/qiskit/blob/main/CODE_OF_CONDUCT.md), which is based on the Contributor Covenant. In short: be respectful, assume good intent, and keep discussion technical and kind. Report unacceptable behaviour to the maintainers at m25iqt002@iitj.ac.in.
